# VELO Realty Dynamic Website Project Documentation

## 1. Project Overview
Create a premium real-estate website for VELO Realty Pvt Ltd inspired by:
- https://www.storeys.ae/
- https://drehomes.com/
- https://milestonehomesre.com/

The website should be:
- Fully dynamic from backend
- Ultra-fast and SEO-friendly
- Optimized for 4K images
- Built with React TypeScript frontend
- Express.js backend
- PostgreSQL database

## 2. Branding Guidelines
### Logo
Use VELO Realty logo in navbar, footer, favicon, and loading screen.

### Color Palette
- Primary: Midnight Navy (#1A2B3C)
- Secondary: Kinetic Teal (#00A896)
- Accent: Slate Silver (#8E8E93)
- Background: Crisp White (#FFFFFF)

## 6. Performance Optimization
- Next-gen image formats (WebP/AVIF)
- CDN usage
- Lazy loading
- SSR / SSG where possible
- Code splitting
- Redis caching

## 7. Tech Stack
Frontend:
- React + TypeScript
- TailwindCSS / MUI
- Redux / Zustand
- React Query

Backend:
- Node.js + Express.js
- JWT auth
- Multer / Cloudinary / S3

Database:
- PostgreSQL

## 8. SEO Requirements
